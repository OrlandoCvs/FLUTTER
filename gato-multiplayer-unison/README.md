  <h3>📱 Descripción de la Aplicación</h3>
  <p align="justify">
    <b>Gato Unison</b> Es una plataforma móvil de juegos de estrategia desarrollada en <b>Flutter</b> que permite enfrentamientos multijugador en tiempo real[cite: 119, 120]. Utilizando los servicios de <b>Firebase Authentication</b> para el control de usuarios y <b>Cloud Firestore</b> para la sincronización instantánea de partidas, la aplicación ofrece una experiencia fluida y competitiva dentro de un entorno seguro y personalizado[cite: 122, 128].
  </p>

  <div align="left" style="background-color: #ECF0F1; padding: 20px; border: 2px solid #1B4F72; border-radius: 15px 50px 30px 5px;">
    <h4>✨ Funcionalidades Clave</h4>
    <ul>
      <li><b>Sincronización Real-Time:</b> Los movimientos se reflejan instantáneamente en el dispositivo del oponente[cite: 120, 156].</li>
      <li><b>Gestión de Salas:</b> Creación de partidas con códigos únicos de 6 caracteres para invitar a amigos[cite: 143, 144].</li>
      <li><b>Global Leaderboard:</b> Seguimiento del Top 10 de mejores jugadores basado en victorias acumuladas[cite: 169, 170].</li>
      <li><b>Persistencia de Datos:</b> Registro automático de estadísticas y movimientos de cada partida finalizada[cite: 173, 174].</li>
      <li><b>Autenticación Segura:</b> Sistema robusto de registro e inicio de sesión para cada competidor[cite: 130, 136].</li>
    </ul>
  </div>
